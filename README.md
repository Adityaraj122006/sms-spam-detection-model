SMS SPAM DETECTION MODEL

the model is run on pycharm on which a basic run file called 📁app.py was created and 2 more files📁(vectorizer and model) were created these were the key 
working part of the model overall ( furthter you can make sense of all this by going through the repository)
DATASET-kaggle-  https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset
MULTINOMIAL NAIVEBAYES and tfidf Vectorizer were used
